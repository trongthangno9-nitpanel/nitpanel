🚀 Chia sẻ NITPANEL - cài bằng 1 lệnh

Chọn phương thức host script cài đặt phù hợp. Người dùng chỉ cần dán 1 lệnh vào VPS AlmaLinux / Rocky / RHEL là cài xong.

🌐 Lệnh dùng tên miền (cần trỏ DNS về server này):

▶ Hướng dẫn host qua tên miền tùy ý
Ví dụ: dùng nitscript.netihot.com
1. Trỏ DNS A của domain về IP server này.
2. Vào Websites → tạo mới với domain đó, PHP bất kỳ, không cần DB.
3. Vào File Manager → public_html → tạo file index.sh với nội dung:
# /etc/nginx/conf.d/nitscript-proxy.conf
location = /index.sh { proxy_pass http://127.0.0.1:8765/install.sh; }
4. Hoặc đơn giản: copy nội dung từ - vào index.sh.
⚠️ Bảo mật: nên đặt sau HTTPS và pin checksum trong môi trường yêu cầu cao.
✅ Khuyên dùng cách này: URL ổn định, HTTPS, không phụ thuộc VPS này.
🔗 Lệnh cài chính thức từ GitHub:
curl -fsSL https://raw.githubusercontent.com/trongthangno9-nitpanel/nitpanell/main/one-line-install.sh | sudo bash

GITHUB_USER="username-của-bạn" 2. Push commit → tạo tag v2.4.1 → GitHub Actions tự build.

                Bảo mật: phpMyAdmin chỉ listen trên 127.0.0.1:8766 để không lộ ra internet.
                Truy cập từ máy bạn bằng SSH tunnel:
                
ssh -L 8766:127.0.0.1:8766 root@<server-ip>

Đăng nhập 2 lớp: HTTP basic auth (xem bên dưới) → trang phpMyAdmin (dùng MySQL root user).
